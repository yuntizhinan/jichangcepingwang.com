Shadowrocket (小火箭) 零基础上手与配置教程 (iOS 苹果全指南)

iOS / iPadOS 更新于 2026-10-04 阅读时间：约 10 分钟 作者：闪电评测团队
导读：Shadowrocket（俗称小火箭） 是苹果 iOS/iPadOS 平台上口碑最佳、操作最简便的高性能代理软件。由于中国大陆 App Store 政策下架，用户需要通过非中国大陆区 Apple ID 购买下载。本文将为您清晰拆解下载、配置与高阶使用的全流程。

一、获取与登录外区 Apple ID 安全规则

由于小火箭仅在海外区 App Store 上架（买断售价 $2.99），获取软件前请严格遵循以下安全防封规则：

  • ⚠️ 极其重要安全警告： 严禁在 iPhone / iPad 的 系统设置 -> iCloud 界面登录非本人账号！一旦账号被锁，将导致手机无法解锁砖化！
  • 正确操作位置： 仅在桌面打开 App Store (应用商店) 软件内部进行账号切换。

二、Shadowrocket 下载全步骤拆解

  1. 在 iPhone 桌面点击打开 App Store，点击右上角的个人头像进入账户页面。
  2. 滑动到最底部，点击 “退出登录 (Sign Out)”。
  3. 在顶部输入您准备好的美区或港区 Apple ID 账号与密码登录（若提示双重验证，按提示接收验证码输入）。
  4. 登录成功后，App Store 页面会自动刷新语言。在搜索框输入 Shadowrocket。
  5. 认准正版小火箭图标（阴影小火箭图标，开发者为 Lining Guo），点击下载安装（售价 $2.99，可用外区礼品卡兑换或购买已购共享号）。
  6. 下载完成后，重新点击 App Store 头像滑动到底部退出共享账号，登录回您自己的个人 Apple ID。软件已永久安装在设备中。

三、节点订阅导入与一键连接

配合优质专线机场，小火箭可实现秒开 4K 视频。您可以参考 2026 年机场排行榜 选择 极连云 或 速界机场。

  1. 登录机场后台，找到“一键导入”或“复制 Shadowrocket 订阅链接”。
  2. 打开 Shadowrocket 软件，点击右上角 “+” 号。
  3. 在 “类型 (Type)” 下拉菜单中选择 “Subscribe (订阅)”。
  4. 在 “URL” 输入框中粘贴复制的订阅链接，在“备注”中填入机场名字，点击右上角 “保存 (Save)”。
  5. 小火箭将自动拉取节点列表。在首页列表中，点击选择一个延迟最低的专线节点（如香港 IEPL）。
  6. 开启顶部的 “未连接” 主开关。首次开启时系统会弹出提示 “Shadowrocket”想添加 VPN 配置，点击“允许”并输入 iPhone 解锁密码授权。

四、智能规则分流模式详解

小火箭支持灵活的全局路由规则，在主界面“全局路由”处可自由选择：

  • 配置 (Config) 模式【默认推荐】： 自动识别流量。访问百度、淘宝、微信等国内流量直接连接；访问 Google、YouTube、ChatGPT 自动走代理节点。省电且无缝。
  • 代理 (Proxy) 模式： 强制手机全部流量走代理节点。适合特定受限网站测试。
  • 直连 (Direct) 模式： 手机所有流量直接连接，相当于关闭代理。

❓ Shadowrocket 用户常见问题 FAQ (8条)

Q1: App Store 搜索出来的“小火箭”图标很多，如何辨别正版？
答：请认准软件英文全名 `Shadowrocket`，应用图标为正方形阴影小火箭，开发者（Developer）名称必须为 `Lining Guo`。App Store 中有大量名称相似的山寨仿冒收费应用，请务必认准开发者信息再付费下载。
Q2: 为什么开启小火箭开关时提示“添加 VPN 配置失败”？
答：通常是因为系统中有旧的 VPN 描述文件残留冲突。解决办法：进入 iPhone `设置 -> 通用 -> VPN 与设备管理`，清理掉其他无关的 VPN 配置文件，随后重启 iPhone 再次尝试连接授权。
Q3: 共享外区 Apple ID 登录时提示“账号锁定”或“安全双重验证”怎么办？
答：共享账号使用人数过多极易触发苹果风控。强烈建议前往苹果官网（appleid.apple.com）使用自己的全新 Outlook/Gmail 邮箱，花 5 分钟自由注册一个专属的美区 Apple ID，安全且永不封号。
Q4: 为什么小火箭连接后可以正常上网，但点击节点测速全部提示 Ping 失败？
答：这是因为小火箭默认的测试 URL 在国内受阻。解决办法：进入小火箭底部 `设置 -> 测试分组 -> 测试网址`，将 URL 改为 `https://www.google.com/generate_204` 或 `https://cp.cloudflare.com/generate_204` 即可恢复精准测速。
Q5: 如何配置小火箭在后台自动刷新节点订阅？
答：在小火箭底部进入 `设置 -> 订阅`，开启 `打开时更新` 和 `自动更新` 开关。这样每次打开小火箭时都会自动同步机场最新的节点列表与流量信息。
Q6: 小火箭配合机场节点支持畅刷海外版 TikTok 和对话 ChatGPT 吗？
答：完全支持。运行小火箭时，选择拥有原生双 ISP 住宅 IP 的机场节点（如 极连云 或 速界机场），并在小火箭设置中开启 UDP 转发即可稳定流畅使用 TikTok 和 OpenAI 服务。
Q7: 开启小火箭后连接 Wi-Fi 正常，但切换到 4G/5G 手机蜂窝网络就断网？
答：请检查 iPhone `设置 -> 蜂窝网络`，下拉找到 `Shadowrocket`，确保其网络访问权限已勾选为 `WLAN 与蜂窝网`，避免系统阻断了小火箭在蜂窝网络下的联网权限。
Q8: 小火箭的“代理共享”功能怎么用？可以给同 Wi-Fi 下的 iPad 或 Mac 加速吗？
答：可以。在小火箭 `设置 -> 代理 -> 允许代理` 开启开关，界面会显示 iPhone 的局域网 IP 地址和端口（默认 1082）。在同一 Wi-Fi 下的 iPad 或电脑中，将网络代理设置为手动，填入该 IP 与端口，即可无需安装客户端共享科学上网。
